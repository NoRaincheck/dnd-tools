1. System Overview

Why Burning Wheel — And the AI Fix

  • Beliefs drive play. Every PC carries 3 Beliefs I believe ___ and will ___. Artha flows only when Beliefs are challenged, pursued, or broken.
  • Intent & Task + Say Yes or Roll. No roll without opposed intent. If failure isn't interesting, Say Yes. If you roll, Let It Ride locks result.
  • Counted successes, not sums. Roll Nd6 where B≥4 / G≥3 / W≥2 per shade, vs Obstacle.
Failure is not null — GM must narrate a complication that matters and still advances the world.

Core Loop

Belief framing (3 BITs + Artha) → Scene framing (intent)
  → GM: Say Yes or set Ob 1–10 → Declare Help / FoRK / Artha BEFORE roll
  → Roll Nd6 vs Ob → Success/Failure → narrate complication (Let It Ride)
  → Log Routine/Difficult/Challenging → Award Fate/Persona/Deeds
  → Next intent (Duel of Wits / Bloody Versus / Fight!)

This repo implements the Hub & Spokes loop (Intent & Task, Versus, Bloody Versus, Circles/Resources/Steel) plus Duel of Wits; full Fight! and Range & Cover are flag-gated (v1 defaults to Bloody Versus).

3. Core Mechanics

3.1 The Die & Shades

success = 1 if die ≥ threshold(shade)   B≥4, G≥3, W≥2
total = count(successes) + fate_explosions(6s)  // each 6 explodes, recursive

3.2 Intent & Task, Obstacle, Say Yes

ObLabelUse
1EasyEveryday, aided
2RoutineProfessional with right tool
3DifficultDefault for Versus
4–5HardInteresting but nonessential
6+ExtremeReserve for 3-pt spends
7–8LegendaryCap; use staged tests

3.3 Simple Test

  1. Declare intent + task + skill/stat + belief_ref
  2. GM sets Ob 1–10
  3. Declare Help / FoRK / Artha before roll (tool-gated)
  4. Roll: exponent + help + FoRK + persona (+ fate explosions)
  5. ≥Ob → success, else failure = belief-targeted complication; Let It Ride

3.4 Help & FoRKs

Help +1D per helper (cap 3, needs B2 + narration). FoRK +1D per related skill (cap 2, once/session, not the tested skill).

3.5 Versus & Bloody Versus

Versus: both roll vs opponent successes, high wins (tie→defender). Bloody Versus: single-exchange brawl, margin → wound via PTGS (v1 default for combat).

3.6 Let It Ride

Outcome stands for the session until intent, task, or conditions change. Second identical test returns {error:"Let It Ride"} unless changed_task|changed_intent|session_advanced.

4. Running the Game

4.1 Belief Lifecycle

Prep situation × PC Beliefs, not railroad. Every scene must reference a belief_ref.

4.2 Circles & Resources & Steel

  • Circles Ob 1–4 by power; failure = hostile introduction (never empty).
  • Resources Ob 1–4 by price; failure = Tax (−1 exponent).
  • Steel vs hesitation Ob; fail → hesitate / stand-and-drool / flee.

4.3 Duel of Wits

Body of Argument = Will + skill. Volleys: Point / Rebuttal / Dismiss / Feint / Obfuscate / Incite / Avoid. First to 0 BoA loses, then Compromise.

4.4 Bloody Versus vs Fight! / Range & Cover

Escalation: Versus → Bloody Versus (v1) → Fight! (flag) and Range & Cover (flag). Weapon IMS decides wound class.

6. Example Play

GM: Guard bars granary. Belief: "Duke is starving town and I will prove it by taking a sack."
Player (Persuasion B3): Intent get past without violence; Task persuade.
GM: Ob 3. Declare Help/FoRK/Artha before roll.
Player: brother Help +1D (Persuasion B2), FoRK Oratory-wise +1D, 1 Persona +1D → 6D vs Ob3 → [4,5,2,6,1,4]=4 successes → success.
→ Difficult test logged.

Later Bloody Versus vs Steel B3 hesitation → fail; Brawling B3 vs B4 margin 2 → Light wound (-1D).

7.3 Dice Extension

def roll_bw(pool:int, shade="B", fate_open=False):
  th={"B":4,"G":3,"W":2}[shade]
  dice=[rng.randint(1,6) for _ in range(pool)]
  successes=sum(d>=th for d in dice)
  if fate_open: # each 6 explodes recursively

8. The AI Fix — Rigid Prompt Templates

Intent & Task + Belief gate

I am acting on Belief [#2: "I believe the Duke is a traitor…"]
Intent get past guard without violence; Task Persuade B3.
→ declare_intent(..., belief_ref=2) and await set_ob before Help/FoRK/Artha.

Artha gate

Help brother +1D, FoRK +1D, 1 Persona +1D, 1 Fate open
Pool 3+1+1+1=6D B≥4 → spend_artha(fate=1,persona=1) then roll_test(Ob3)
Show dice/explosions/successes/class BEFORE narrating.
Let It Ride: same intent+task+scene is BLOCKED until changed_task/changed_intent/session_advanced.
Failure: give belief-targeted complication — not null — e.g. guard lets pass but confiscates ledger.
